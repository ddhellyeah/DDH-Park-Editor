# DDH Park Editor (Quick Drop+)

Works with skate.'s own Quick Drop. Drop objects as normal, then press **F6** to fine-tune them with handles, like the DDH Object Maker's 3D maker.

- **W** move: drag the red / green / blue arrows (they face the way the object does), or the coloured squares to slide along a side
- **E** turn: drag the green ring. The red ring tilts it forward and back, the blue ring to the side (also Tilt X / Tilt Z in the panel; Level puts it flat)
- **R** size: drag a corner of the green box
- The object follows as often as the game takes edits, and lands exactly where you let go
- Click another placed object to pick it. Drag empty space to turn the view, right-drag to slide it, scroll to zoom, arrows and PgUp / PgDn to fly it
- **G** steps (0.25 m, 15°, 0.1), **Shift** bigger steps, **Ctrl+Z** undo, **F** look at the object, **Esc** done
- **T** snap to objects (on to begin with): while you drag, the object's sides meet or line up with the objects near it, and the turn ring catches their turn. What it snapped to is outlined in blue. Hold **Ctrl** to drag without it. Side by side, they share height: an object that meets another side to side takes its height (bottoms level, or tops level when that's less of a move, up to 1 m), whichever handle moves it. Among several objects the closest one comes first, and it keeps to the one it snapped to (no flicking) until another is clearly closer. Objects snap by their outlines: the shape they fill seen from above (a curved bench is a curve, not a box), side to side, and they turn to meet a side flat. Outlines come from the model itself where it can: the Object Maker's models (built in), or the game's model found by the object's name. Anything else is measured with rays to about half a millimetre, and after a snap the seam is checked and the outline fitted to the real side. When it meets an object that is turned, it takes that object's turn so the sides meet flat (pull it away and its own turn comes back). Works with objects from any mod: the Object Maker's sizes are built in (`plugin/sizes.lua`); anything else is measured with rays the first time it is near the picked object (keep it still a moment) and remembered from then on. If a size comes out wrong, pick the object and press **Measure it again**. Objects you can't skate on (no collision) can't be measured and snap by their middle point
- The panel on the right (drawn by the editor itself): what's picked at the top, then **+ Add object / Undo / Controls**, then three tabs:
  - **Edit**: Move / Turn / Size handles; position, height, turn, size and tilt with − / + buttons (by the step size) — click a number to type it; Straighten, Size 1, Look at it; step size (Fine / Normal / Big)
  - **Snap**: snap to objects, what it snaps to (Auto / Next object / Off), grid, drag in steps
  - **Park**: the group, copy tools, every object in the park (search, All / Near / DDH, scroll with the wheel), save as park mod
  - **Controls** opens a picture of the controller and the keys with what each one does
- On older ReSkate the panel falls back to the old sliders

**Controller** (Xbox or PlayStation), like Quick Drop: **LB + D-pad right** opens it.
- Not holding anything: the left stick flies around freely, **RT / LT** up / down, **D-pad up / down** zoom, **D-pad left / right** next object. The cross in the middle shows which object **A** picks up
- **A** with nothing under the cross opens the **add window**: pictures of every Quick Drop object by category (LB / RB). **A** adds the chosen one where the cross is and hands it to you to move (**B** right away takes it back). Mouse: the panel's **Add object** button, click a picture.
- **A** on an object picks it up, **A** again puts it down. **B** cancels (it goes back where it was); with nothing held **B** closes
- Holding: left stick moves it, **RT / LT** raise / lower, **LB / RB** turn (15°), **D-pad up / down** size; it snaps to objects (keep pushing to go past)
- **X**: not holding, copies the object the cross is on and hands you the copy (**B** right away takes the copy back); holding, drops a copy where it is (tilt and all) and keeps the original in hand. **Y** twice removes the object the cross is on (or the one held)
- Right stick: not holding, looks around where the view stands (like Quick Drop); holding, circles round the object. (Controls: "Invert look up/down" and "left/right" switches), **R3** looks at the object, **View** undo, **Menu** switches Fine / Normal / Big (the same as the panel buttons: turn 1° / 15° / 45°, size 0.01 / 0.1 / 0.5, slow / normal / fast movement), hold **L3** for Fine while held
- **Snapping in crowded spots:** it snaps to the object it meets. After that it only adds more snaps to that same object, or to another object it meets face to face (fitting into a gap). It no longer lines up with objects further round about: only the nearest object lines up from a distance, others only within 1 m
- **Choose what it snaps to:** **View** switches snapping between auto (the nearest) → one object → off; tap **L3** to target the nearest object, then the next nearest, and round again (holding or carrying a set: what it snaps to; not holding: what the cross is on, so A picks it up) (keyboard **Tab**, or the panel's Auto / Next object / Off buttons). The chosen object is outlined in orange and named next to the held one. Holding L3 is still Fine. Putting it down goes back to auto
- **Undo and redo:** **LB + View** undoes, **RB + View** redoes (keyboard **Ctrl+Z** / **Ctrl+Y**, or the panel's Undo / Redo). Moves, turns, sizes, group moves, copies, placed sets and removed objects can all be undone and redone; removed objects come back exactly where they were, selected as a group
- **Arrange a group** (panel, Park tab): **Mirror left / right**, **Mirror front / back** (seen from the picked object), **Line up**, **Space evenly**, **Same height**. One undo puts them back
- **Sets tab:** each saved set shows its layout from above, with **Place**, **Rename**, **Update** (saves the selected objects over it; click twice) and **Delete** (click twice). A carried set also turns to meet a turned object flat when it snaps to it, like one object does
- **Sets (save a build and drop it anywhere):** make a group (or pick one object), open the panel's **Sets** tab and press **Save as a set**, give it a name. Later, on any map or server, place it from the Sets tab (**Place**) or from **Add object > Sets** (with the controller): you **carry** it first: it shows as purple outlines that follow the cross (left stick moves it, RT / LT up / down, LB / RB turn), and nothing is placed until you press **A**. **B** cancels. Once down, every object keeps its place, turn, size and tilt next to the others and it is picked as a group; **View** undoes it. Sets are files in the plugin's data folder (**Open the sets folder**): send a set's .json to a friend and they put it in theirs. Objects from mods that aren't installed are left out
- **Groups (several at once):** **hold A** and sweep the cross over objects: each one it passes over goes in the group (let go of A when done; a quick tap of A still picks up as before). **RB** on an object puts it in the group (again takes it out), **LB** clears the group; with the mouse, **Ctrl+click**. Group members are outlined in purple. Picking up any of them (A, or dragging its handles) takes the rest along: they keep their places and turn with it, show as outlines while held, and move when you put it down (the game takes 4 edits a second, so they go one after another). **Y twice** (quickly) with objects selected removes every selected one. **Y** once on a selected one takes it out of the selection; keep Y down and sweep the cross to take more out. **X** copies the whole group, **Y** twice while holding it removes it all, **View** undoes it all
- **Zoom while holding:** **D-pad right** zooms in, **left** zooms out (like the mouse wheel). Rows of copies are made with the copy tools (R3)
- **Copy tools:** while holding, **R3** (or the panel's **Copy tools** button) opens a window: a **Row** (sideways, forward or up, with a gap), a **Circle** (how many, its size, facing the middle or the same way) or a **Grid** (across × deep). The copies show as green outlines before they're made; **A** (or the button) makes them. One undo takes them all away again. Up to 200 copies at once
- **Grid snap:** in the copy tools or the panel (Off, 0.25, 0.5, 1, 2 m). Moving an object freely, it lands on the ground grid, unless it's snapping to another object
- **Pictures in the add window:** every DDH / RAW object shows its picture (they come with the mod). The game's own objects show their outline from above (when known) or their initials
- **Controller view:** with the controller, the screen works like Quick Drop: a cross in the middle, the name of what it's on, the buttons for what you can do now along the bottom, and what's set (steps, snap, group, grid) along the top. No move/turn handles while you use the controller (they come back when you use the mouse). Leaving F6 and coming back starts with nothing picked (unless you dropped something with Quick Drop in between)

Without opening it: hold **Ctrl** and use [ ] (turn), PgUp / PgDn (height), Z / X (size), arrows (slide) on the last dropped object.

Online: press **Save as park mod (for online)** in the panel. It writes the whole park on this map, tilts and all, as a park mod and opens its folder: copy that folder into ReSkate's `Mods` folder, then Build > Park mods > Load (in multiplayer the host loads it, and everyone sees the tilts). Park mods only work on the game's own maps.

Tilting: the game saves only a turn about up, so this plugin holds tilted objects itself (fixed, skateable) and remembers each tilt per map, putting it back whenever the park loads. Offline only, at most 32 tilted objects, and only while this plugin runs; while you move a tilted object it shows flat for a moment. Tilted objects snap too, face to face: brought against a tilted object (its side or its top), an object takes its tilt so the two sit flat, and gets its own back when pulled away. A park with objects from a mod that is not installed cannot be changed at all, by this or by Quick Drop.

Needs ReSkate 2.1.2 or newer. Unzip into ReSkate's `Mods` folder.
